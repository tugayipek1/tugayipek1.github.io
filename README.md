# tugayipek1.github.io

Personal CV site of **Tugay İpek**, Full Stack Software Engineer.

Live: https://tugayipek1.github.io

Plain HTML and CSS with no build step. Fonts (Inter, JetBrains Mono) and tech icons (Devicon) are self-hosted under `assets/`.

```
index.html            page content
assets/css/style.css  styles (light/dark, print-friendly)
assets/js/main.js     theme toggle + active nav section
assets/img/           portrait, favicon
assets/icons/         Devicon SVGs
tugay-ipek-cv.pdf     downloadable resume
```

To update the resume, replace `tugay-ipek-cv.pdf` and edit the matching section in `index.html`.
